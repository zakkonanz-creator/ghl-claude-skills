- Custom-field options come from the location custom-field catalog (`GET /locations/{loc}/customFields/search?...`). Custom fields store their location-specific key/ID shape rather than the standard Email key shown here.

## Quirks

- The action picker contains multiple app actions named Create contact. The native card has DOM id suffix `add-action-create_update_contact`; its panel title is Create update contact.
- The panel says this action only works with contactless execution methods such as Inbound webhook.
- If a contact already exists by email/phone deduplication, this action updates it instead of creating a duplicate.
